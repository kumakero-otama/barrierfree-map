OpenStreetMapのAPIは何をするのか

調べた結果、OpenStreetMapに直接関係するAPIは GET /api/osm-tactile-ways です。 これは、地図のある場所の近くにある「点字ブロック関係のOpenStreetMapデータ」を取り出すためのAPIです。

まず一言でいうと

ユーザーが「この場所の近くに点字ブロックの情報はあるかな」と知りたいときに使うAPIです。 サーバーは OpenStreetMap そのものを直接読むのではなく、 Overpass API という検索サービスに問い合わせて、 その結果をアプリで使いやすい形に直して返します。

何を入力するのか

centerLat 必須。中心にしたい場所の緯度です。地球上での「たて位置」です。
centerLng 必須。中心にしたい場所の経度です。地球上での「よこ位置」です。
radiusKm 省略可。どこまで広く探すかを km で指定します。指定しないと 10km です。大きすぎても最大 10km に丸められます。

つまり、「どの場所を中心に」「どれくらいの広さで探すか」を渡します。

どんなデータを探すのか

このAPIは、OpenStreetMapの中でも主に点字ブロックに関係するタグを探します。

tactile_paving

点字ブロックがあるか、両側にあるか、見やすい色か、など。

tactile_paving:orientation

ブロックの向き。進行方向に対して平行か垂直か。

tactile_paving:direction

道の左側か右側か。

tactile_paving:condition

状態がよいか、普通か、など。

tactile_paving:pattern

棒状の誘導ブロックか、点状の警告ブロックか。

どんな出力をするのか

返ってくるのは JSON です。中身はだいたい次のような意味です。

success うまく成功したかどうか。
centerLat, centerLng 中心として使った場所。
radiusKm 実際に使われた検索半径。
count 見つかった地物の数。
features 見つかった地物の一覧。地図に線や点として描きやすい形で入っています。

features の中身

1つ1つの地物は、主に次の2種類です。

  • LineString: 線です。歩道や道沿いの点字ブロックのように、長さのあるものを表します。
  • Point: 点です。特定の1か所だけを表します。

各地物には、たとえば次のような情報が入ります。

  • osm_way_id または osm_node_id: OpenStreetMap上の番号
  • osm_type: way か node
  • matched_tag_key: どのタグで見つかったか
  • matched_tag_value: そのタグの値
  • geometry: 地図に置くための位置情報

具体例

たとえば、次のように呼び出します。

GET /api/osm-tactile-ways?centerLat=35.6812&centerLng=139.7671&radiusKm=1

意味は「東京駅の近く1kmで、点字ブロック関係のOpenStreetMapデータを探して」です。

返り値のイメージは次のようになります。

{
  "success": true,
  "centerLat": 35.6812,
  "centerLng": 139.7671,
  "radiusKm": 1,
  "count": 2,
  "features": [
    {
      "type": "Feature",
      "properties": {
        "osm_way_id": 123456,
        "osm_type": "way",
        "matched_tag_key": "tactile_paving",
        "matched_tag_value": "yes"
      },
      "geometry": {
        "type": "LineString",
        "coordinates": [[139.76, 35.68], [139.77, 35.68]]
      }
    }
  ]
}

エラーのときはどうなるか

  • 400 invalid_center: 緯度や経度が数字として正しくないとき。
  • 405 method_not_allowed: GET 以外の方法で呼んだとき。
  • 500: サーバー内部の設定や処理で問題が起きたとき。
  • 502 osm_upstream_error: OpenStreetMap検索に使う外部サービス側で失敗したとき。

ポイント

このAPIは「OpenStreetMapの全部」を返すものではありません。 点字ブロックに関係するものだけ を、 指定した場所の近くから拾って返す、かなり目的のはっきりしたAPIです。
