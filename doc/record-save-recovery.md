# 記録保存の復旧（2026-11-22）

一般モードの標準 `tactile_paving` 付与までPRO限定として拒否していた不整合を修正。
任意タグのPRO制限と記録所有者確認は維持する。

## サーバー保存済みデータ

バックアップ取得後、稼働環境の設定で次を実行する。

```sh
node tools/recover_saved_record_tags.js
node tools/recover_saved_record_tags.js --apply --queue-reviews
```

デフォルトは読取りのみ。対象は11月1日以降の有効・終了済み経路。
非ゲスト・非PROでタグが一つもない記録だけに標準タグを補完する。
既存タグ・経路・メモ・日時・所有者は上書きしない。
トランザクション内で復旧前後のハッシュを照合し、失敗時はロールバックする。
変更は追記型監査へ保存する。重複実行しても同一タグ・確認項目を増やさない。

`--queue-reviews` は公開タグのある非ゲスト記録の未登録分を確認待ちに収集する。
OSM操作は空のローカル仮案であり、再マップマッチングが必須。
実送信ガードで仮案の送信を禁止し、管理者が将来承認した場合のみ再計画する。
このツール自身はOSMにアクセスせず、通知は未送信キューに登録するだけ。

## 端末内の停止済み送信

UI0 v1.30.13は本人所有、経路・終了保存済み、タグ保存403で停止したジョブだけを
一度再開する。保存済み段階とペイロードを保持し、二重経路を作らない。
同じ端末・同じアカウントでオンライン起動する必要がある。
他の権限エラーや他アカウントのジョブは解除しない。
端末だけのデータの全回収完了はサーバー側からは保証できない。

## 継続的な照合・通知

同日の追加改善で、APIの同一プロセスが起動5秒後と処理完了60秒後にDB照合を行う。
保存APIから切り離しているので、通知の遅延・障害で保存応答を止めない。
同時実行を抑止し、失敗時も原データを保持して次回に再試行する。
非ゲストで公開タグのある有効・終了済み記録が対象。本人限定だけの記録は除外。
メールは1周期最大10件、失敗時5分以上の間隔を空け最大5回試行し、失敗状態もDBに残す。
仮案はOSM実行ガードで停止する。復旧登録だけでOSM編集は発生しない。
一覧・詳細APIは他人の本人限定記録を404または一覧対象外として扱う。
